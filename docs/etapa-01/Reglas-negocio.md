***Reglas de negocio:***



&#x20;   **• RN01 —** Un cliente puede realizar una o varias compras, pero cada compra pertenece a un único cliente. 

&#x20;   **• RN02 —** Cada cliente tiene un código identificador (DNI/CUIT) único. 

&#x20;   **• RN03 —** Un producto puede estar incluido en una o varias ventas, y una venta puede incluir uno o varios productos. 

&#x20;   **• RN04 —** Cada producto tiene un código identificador único y pertenece a una única categoría (PC Pre-armada, Notebook o All In One). 

&#x20;   **• RN06 —** Un vendedor puede registrar una o varias ventas, pero cada venta es registrada por un único vendedor. 

&#x20;   **• RN07—** Un producto puede tener stock disponible igual a cero, pero nunca un valor negativo.

&#x20;   **• RN09 —** Una venta puede pagarse con un solo método de pago, y un método de pago puede estar asociado a una o varias ventas.
